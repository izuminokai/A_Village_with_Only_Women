# 定住希望

- 型
    - True/False
- セット条件
    - [村長]に「村に定住したい」と伝える
        - 「定住」という単語が入っていなくても、村に住むことが前提となるならそれは定住希望と見なされる。「ハーレムを作りたい」など
- 効果
    - [シナリオ.トゥルーエンド]で分岐する

# 真相解明

- 型
    - True/False
- セット条件
    - [シナリオ.真相開示]をクリア
- 効果
    - Falseの場合
        - [同行者]以外のNPCに、年齢や、[村.起源]を尋ねたとき、嘘をついたりはぐらかされる
    - Trueの場合
        - 真実を教えてくれる

# 急病人

- 型
    - NPC名
- セット条件
    - [シナリオ.決断の時]を開始

# 残り時間

- 型
    - 数値
- セット条件
    - [シナリオ.神鏡破壊]で大岩を動かした際に初期値がセットされる
- 説明
    - [副長]が追いついてくるまでの残り時間を数値で表示する
    - 時間内に神鏡を破壊できればクリア
    - 0分になると[副長]に追いつかれ、取り押さえられる
        - ->[シナリオ.神鏡破壊.捕まった場合](../scenario/09_release.html)

# 殺害

- 型
    - 殺害したNPC名のリスト
- セット条件
    - NPC殺害
        - ただし[巫女]の殺害に限り、このフラグは付与されない
- 効果
    - 殺害しても露見しなければ即エンディングにはならず、そのままメインルートを進められる
    - バッドエンド以外のエンディングを迎えそうになった場合、直前で落石や事故に遭って死ぬ。死の間際、殺したNPCの顔を幻視する（バッドエンド）
