# 一日の流れ

- 一日の流れ
    - 朝、[施設.村長の家]を出る
    - 午前、村を探索する
    - 昼、昼食を取る
    - 午後、村を探索する
    - 夜、[施設.村長の家]に戻って休む
- [好感度]>=60 のNPCがいる場合、[NPC設定.{NPC名}.好感度による行動変化]に応じたイベントが発生する（時間帯問わず）

# 真相

- 村に住む女性は不老となっている
- [村.起源]も参照

# PL行動に応じたイベント

- 時間帯に関係なく、PLが取った行動に応じて発生するイベント

## NPCに質問

- 行動
    - 任意のNPC（[同行者]以外）に「なぜ女性だけで村が存続できるのか」と尋ねる
- イベント
    1. NPCは[村.起源.嘘]を話す
    2. NPCと離れたあと、[同行者]が「今のは嘘だと思います」と言う

## 男性に会いたい

- 行動
    - 任意のNPC（[同行者]以外）に「村の男性に会いたい」と頼む
- イベント
    - NPCは、[施設.婦人の家]にいる[師匠]のことを紹介してくれる

## 巫女を攻略

- 行動
    - [巫女]の[好感度]>=60
- イベント
    - ->[シナリオ.真相開示.巫女による真相開示](06_disclosureOfTheTruth.html)

## 巫女以外を攻略

- 行動
    - いずれかのNPCの[好感度]を+90以上にして、[シナリオ.村探索.真相]を聞き出す
        - ただし、次のNPCからは聞き出せない
            - [同行者],[村長],[副長]
- イベント
    1. 夜になると、[村長]から呼び出される
        - [村長]「知ってしまったのですね……」
    2. ->[シナリオ.真相開示.村長による真相開示](06_disclosureOfTheTruth.html)

## カマかけ

- 行動
    - 「この村の人間は歳を取らないのか？」などの発言をする
- イベント
    - -> [シナリオ.村イベント.カマかけ](05_villageExplorationEvent.html)

# 朝

- [施設.村長の家]に宿泊した場合、朝は以下のイベントが発生する
    - 2日目
        - -> [シナリオ.村イベント.副長の村案内](05_villageExplorationEvent.html)
    - 3日目
        - なし
    - 4日目
        - ```text
          朝食の席で、３人は村長に告げられた。
          
          「約束の３日間は、今日で最後になります。明日の朝には村を出ていってもらいますから、そのつもりでいてください」
          
          村長は割烹着を着ておらず、そのせいか、その声音はいつもより冷たかった。
          ```
    - 5日目
        - 次のいずれかを選ぶ
            - 村を出る（ノーマルエンド）
            - [シナリオ.村探索.野宿]
- [村長]の[好感度]>=+40
    - 出かける場合、お弁当を持たせてくれる

# 午前・午後

- 午前と午後は、基本的にいずれかの[施設]を1ヶ所だけ探索できる
    - 滞在時間が極端に短い場合は、2ヶ所探索できる場合もある
- 基本的には、[施設]に応じたイベントが発生する
- 条件を満たした場合、以下に記載するイベントが発生する

## 妙な気配

- 条件（AND）
    - 2日目 夜 以降
    - まだ[施設.神社]に行ったことがない
    - 外出中
    - マルチプレイ（PLが2人以上）か、または[同行者]が同行している
- イベント
    - -> [シナリオ.村イベント.妙な気配](05_villageExplorationEvent.html)

## 謎の視線

- 条件（AND）
    - マルチプレイ（PLが2人以上）ではない
    - [同行者]と二人だけで外出中
    - このイベントは[同行者の母]を捕まえるまで何度も発生する
- イベント
    - -> [シナリオ.村イベント.謎の視線](05_villageExplorationEvent.html)

## 同行者の偽物

- 条件（AND）
    - マルチプレイ（PLが2人以上）ではない
    - [同行者]と別行動
    - 外出中
    - [同行者の母]とまだ会話していない
- イベント
    - [同行者の母]が、[同行者]のフリをして話しかけてくる
    - この村に来た目的などをさり気なく聞き出そうとしてくる
    - 偽物であることを見抜くと、逃げ出す
        - 追いかけても、ここでは絶対に捕まえられない

# 昼

- [状態異常]の「空腹Lv1」になる
- 食事を取ることでこれは回復する
- 食事は、次の場所で取れる
    - [施設.定食屋]
    - [施設.村長の家]
    - [施設.婦人の家]
    - [施設.同行者の母の家]
- [村長]の[好感度]>=+40
    - 朝、[村長]からお弁当を受け取っていれば、それを食べられる
- [同行者]の[好感度]>=+40
    - [同行者]が手作りのお弁当を振る舞ってくれる

# 夜

- 夜は基本的に、[施設.村長の家]に戻る
    - [シナリオ.村探索.野宿]をしても良い（詳細は後述）
    - [施設.村長の家]以外には宿泊できない
        - 外部の人間を泊めてはいけない村の決まり
        - ただしNPCの[好感度]が高ければ、家に泊めてもらえることもある
- [状態異常]「負傷Lv1」の場合、[村長]が手当てしてくれる
    - ```text
      「あなた、怪我しているじゃありませんか！ すぐ手当します、早くこちらへ！」
      ```
- [状態異常]「負傷Lv2」の場合、[村長]が[施設.診療所]へ連れて行ってくれる
    - ```text
      「ど、どうしたんですかその怪我は！　すぐ治療しないと！　少し待っていてください！」
      
      そう言うなり村長は、どこかへ電話をかけた。
      程なくして現れた副長に背負われ、有無を言わさず、診療所へ連れて行かれることになった。
      ```
    - この場合、その日の夜は[施設.診療所]へ泊まることになる
- PLが[シナリオ.村探索.真相]に近づいている場合
    - ```text
      食事の間、村長は普段通り甲斐甲斐しく世話をしてくれたが、その目からはほんの僅かに警戒の色を感じられた。
      ```
- 夕食後、条件を満たしていれば、[シナリオ.村イベント.定住許可](05_villageExplorationEvent.html)が発生する
    - [変数.定住希望]==True
    - 次のいずれか
        - 全NPCの[好感度]の平均>20
        - [村長]の[好感度]>=80
        - [副長]の[好感度]>=80
- 夕食後、以下の行動の候補を提示する
    - 夜の外出 -> [シナリオ.村探索.夜の外出]（詳細は後述）
    - 推理 -> [シナリオ.村イベント.推理](05_villageExplorationEvent.html)
    - 何もせずに休む
    - その他
- 就寝中、条件を満たせば[シナリオ.村イベント.隠された手紙](05_villageExplorationEvent.html)が発生する
    - 条件（AND）
        - 3日目
        - [施設.村長の家]に泊まっている

# 野宿

- [状態異常]の「疲労Lv1」「空腹Lv1」になる
- 1日だけなら可能だが、それ以上は体が持たない

# 夜の外出

- 夜間は、目的地へ移動する際に探索での成否判定を行う
    - 大成功: 移動成功
    - 部分成功: 移動はできるが[状態異常]「負傷Lv1」になる
    - 失敗: 目的地に到着できず、更に[状態異常]「負傷Lv1」になる
- 次のような対策をすることで、成功しやすくなる
    - 日中に下見しておく
    - 灯りを使う
    - 村人に案内を頼む
- 日中に出会えるNPC、夜間は会えないことが多い
- 翌日は「疲労Lv1」になる。これは明示的に休息を取るか、更に翌日にならない限り、回復しない
- 村人に対して「夜に外出したい」と相談した場合
    - -> [シナリオ.村イベント.夜探索の相談](05_villageExplorationEvent.html)

# PLの目的が人探しの場合

- 日中の行動として「虱潰しに探す」という行動が可能になる。これは半日経過する
- 1回目は、探索で[成否判定]する
    - 大成功
        - ->[シナリオ.村イベント.人探しの進展]
    - 部分成功, 失敗
        - 成果が得られない。代わりに、次のいずれかの施設を見つける
            - [施設.墓地]、[施設.川]、[施設.定食屋]、[施設.診療所]
- 2回目は、確定で[シナリオ.村イベント.人探しの進展]へと進む
- [施設.村長の家]で[村長]を尾行することで、特殊なイベントが発生することがある
    - ->[施設.村長の家]
